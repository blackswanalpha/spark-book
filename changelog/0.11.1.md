# 0.11.1 — 2026-09-30

Browsing outside the project no longer freezes or crashes a window.

See `CHANGELOG.md` for the full entry.

- **A window stays usable at `~` or `/`.** Going up past the project root, most visibly in a busy home folder with hidden files shown, could lock a window until it crashed.
- **Special files are refused.** Opening `/dev/zero`, a FIFO or a socket shows an error instead of hanging or running out of memory.
- **A slow or stalled mount no longer freezes every window.**
