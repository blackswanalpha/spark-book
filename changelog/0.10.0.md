# 0.10.0 — 2026-09-30

Terminals keep running when hidden and reopen where you left them; projects gain search, tasks and pinning; and rich text stops overwriting Markdown and JSON with HTML.

See `CHANGELOG.md` for the full entry.

- **Terminals survive being hidden.** Closing the panel no longer kills builds, dev servers or agents running in it.
- **Terminals reopen where you left them.** Tabs follow the shell's directory, can be renamed, and come back in place after a relaunch.
- **Project-wide search and tasks.** Go to File (Ctrl+P), Find in Files (Ctrl+Shift+F) and Run Task (Ctrl+Shift+B) for package.json, Makefile, justfile, Cargo and Go.
- **Pinned projects** and a keyboard-driven project switcher that marks folders that have gone.
- **Rich text keeps Markdown as Markdown.** JSON opens as code. Content rich text cannot hold opens read-only instead of being overwritten.
- **Format Code works**, with Prettier, for web languages, YAML, Markdown and GraphQL.
