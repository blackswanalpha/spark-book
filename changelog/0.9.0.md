# 0.9.0 — 2026-09-30

The terminal becomes one that agents and full-screen programs can rely on, and the explorer and menus finally do what they say.

See `CHANGELOG.md` for the full entry.

- **Paste images into Claude Code.** Ctrl+V with a picture on the clipboard now reaches the program, which reads the image itself.
- **Shift+Enter makes a newline in Claude Code**, through the kitty keyboard protocol for programs that ask for it.
- **The terminal answers the questions programs ask it**, so fish, prompt_toolkit and crossterm programs no longer stall.
- **Find in the terminal** with Ctrl+Shift+F, across the whole scrollback.
- **Links, file drop and bell badges.** Ctrl+click a URL to open it. Drop a file to type its path. A background tab that rings is marked.
- **A usable explorer** — create, rename, trash, navigate, filter, drag and drop — and **23 menu commands that now work**.
