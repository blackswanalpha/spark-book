# 0.11.0 — 2026-09-30

A Projects window for opening, creating and cloning projects, one window per project. Switching or closing a project no longer throws away unsaved changes.

See `CHANGELOG.md` for the full entry.

- **Projects window.** The Projects button under Terminal lists every project with its branch, path and state, with New Project, Open and Clone.
- **One window per project.** An open project is brought forward instead of opened twice. Shift+Enter opens a new window, Ctrl+Enter uses the window you came from.
- **Clone Repository** with progress, Git's own errors, and a Cancel that leaves nothing behind.
- **Pin, rename, reveal and remove** projects, with the change reaching every open window.
- **Unsaved changes are safe.** Switching or closing a project asks to save, discard or stay.
- **Dialogs are centred** again, and a window that cannot open says so.
